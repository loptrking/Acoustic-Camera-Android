# M4 宽带实时角度测试流程

## 目标

验证 AcousticLens 0.10.0 能否在真实双麦 `CAMCORDER` 路径下，把宽带 GCC-PHAT 时延实时转换为正确的水平声源角度，并在不可靠时降低置信度或拒绝输出。

## 准备

- 安装 `AcousticLens-v0.10.0-broadband-live-doa.apk`。
- 手机横屏，充电口朝右，固定在三脚架上。
- 电脑扬声器播放 `test_noise_500Hz-8kHz_30s_-12dBFS.wav`。
- 手机与扬声器建议相距 1 m，尽量远离墙面、桌面和玻璃。
- 扬声器与手机保持同一高度。

## 角度定义

- `0°`：手机镜头正对扬声器。
- `+30° / +60°`：声源位于手机画面的右侧。
- `−30° / −60°`：声源位于手机画面的左侧。
- App 正角度表示画面右侧，负角度表示画面左侧。

这里的角度始终指“声源在手机/镜头坐标系中的角度”，不是手机绕房间或声源移动了多少度。必须区分三种动作：

1. **手机位置固定，绕自身中心转动**：有效。声源固定不动，手机通过三脚架云台原地偏航；手机不要同时平移，也不要继续让背板始终朝向声源。手机转过 `+30°` 时，声源在手机坐标中应反向变化约 `−30°`。
2. **手机朝向固定，横向平移**：也有效。声源在手机坐标中的角度会变化，但必须量取前向距离和横向距离，手持目测只能用于定性判断左右。
3. **手机绕声源公转，同时始终让背板正对声源**：不用于角度标定。此时两条短边到声源近似等距，声源在手机坐标中始终接近 `0°`；它只能验证中心保持，不能验证 ±30° 映射。

如果以手机为圆心、测试半径为 1 m：

- 30°点：前向距离约 0.866 m，横向距离约 0.500 m。
- 60°点：前向距离约 0.500 m，横向距离约 0.866 m。

推荐保持扬声器和手机位置都不动，只通过三脚架云台让手机绕自身中心旋转到相反角度。App 录制开始后显示“相对转角”，以该数值控制旋转量；不要通过绕声源走动完成。

## 推荐的固定位置偏航实验

1. 手机固定在三脚架上，后置镜头正对扬声器，将此姿态定义为相对转角 `0°`。
2. 开始录制并保持 3 秒。
3. 只转动三脚架云台，使“相对转角”达到约 `+30°`，保持 3 秒。
4. 回到 `0°`，保持 3 秒。
5. 转到 `−30°`，保持 3 秒。
6. 再回到 `0°`，保持 3 秒后停止。
7. 扬声器和三脚架支点在整个实验中不得平移；手机背板只在起点正对声源，转到 ±30° 时不再正对声源。

## 单个角度测试

1. 将声源布置到目标角度并保持静止。
2. 打开 App，确认横屏且充电口朝右。
3. 点击“开始宽带声源定位”。
4. 播放宽带测试音并保持至少 8 秒。
5. 观察方向带、角度和置信度；不要依据瞬时一帧读数，使用稳定后的显示值。
6. 点击“手动停止并保存”。
7. 导出该角度的 session ZIP，并在文件名中保留测试角度。

## 第一轮顺序

先只测试 `0°`。确认中心方向和置信度合理后，再依次进行 `−30°、+30°、−60°、+60°`，避免在系统性符号或零点错误时重复无效实验。

## 验收标准

- 五个角度的左右方向全部正确。
- 0°结果稳定落在 ±10°内。
- ±30°结果误差不超过 15°。
- ±60°结果允许更大波动，但方向必须正确。
- 稳定宽带声源下置信度应持续高于 45%。
- 超出物理时延、声音过弱或相关峰不清晰时，App 应显示拒绝原因，而不是伪造方向。
