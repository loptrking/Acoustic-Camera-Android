# M3 横屏双次设备认证测试指南

适用版本：AcousticLens v0.6.0

## 安装与方向检查

1. 安装 `release/AcousticLens-v0.6.0-landscape-certification.apk`。可以覆盖安装旧版；新版不会把旧版单次 `PASS` 档案视为有效认证。
2. 在 Android 系统中开启自动旋转。
3. 竖屏打开 App，确认界面提示竖屏不可采集，开始按钮不可用。
4. 横屏但让充电口朝左，确认界面要求翻转手机，开始按钮仍不可用。
5. 将手机顶部/听筒方向放在左手边、充电口放在右手边。界面应显示“方向正确”，开始按钮可用。

## 第一次候选初始化

1. 另一部手机或扬声器循环播放 `doc/test_noise_500Hz-8kHz_30s_-12dBFS.wav`。
2. 参考声源放在镜头正前方约 0.8–1.2 m。
3. 始终保持横屏且充电口朝右，只在水平面内按提示左右旋转。
4. 完成 7/7 并等待自动计算。
5. 合格会话应显示“候选参数已保存，需要再次复核”，而不是直接正式通过。
6. 导出 ZIP 到 `result`。

## 第二次跨方向复核

1. 将手机和参考声源的整套相对布置转到另一个绝对方向，建议与第一次相差约 90°至 180°；两者间距和播放音量保持不变。
2. 手机仍保持顶部朝左、充电口朝右。
3. 再完成一次七阶段初始化并导出 ZIP。
4. 只有轴偏差相差不超过 10°、有效基线相对差不超过 30%，第二次才显示“双次认证通过”。否则第二次只会成为新的候选，不会激活正式档案。

## 需要反馈

- 竖屏和反向横屏是否确实无法开始；
- 正确横屏是否显示方向正确；
- 第一次与第二次最终提示；
- 两个导出 ZIP；
- 横屏双栏界面是否有遮挡、按钮无法触及或预览比例异常。
