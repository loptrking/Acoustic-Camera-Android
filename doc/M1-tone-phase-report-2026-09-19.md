# Milestone 1 稳定音与相位连续性报告

日期：2026-09-19  
设备：HONOR PTP-AN10，Android 17  
音频源：VOICE_RECOGNITION

## 结论

1 kHz 和 4 kHz 录音都保留了可追踪的跨时间相位。1 kHz 相位质量良好，4 kHz 相位质量可用于原型验证，但抖动与谐波失真明显高于 1 kHz。纯手机合成孔径路线可以继续，下一阶段应先接入位姿并做受控的 4 kHz 小孔径扫描，不宜直接扩展到复杂声源。

## 1 kHz

- 录音总时长：15.04 s
- 检出的稳定音段：15.019 s
- 估计频率：1000.010390 Hz
- 频率偏差：+0.010390 Hz
- 中位幅度：−53.65 dBFS
- 幅度标准差：2.49 dB
- 5%–95% 幅度范围：−57.20 至 −51.10 dBFS
- 相位残差标准差：10.29°
- 95% 相位残差绝对值：24.59°
- 相邻窗口最大相位跳变：6.14°
- 相干性：0.9841
- 等效路径误差：9.81 mm RMS
- 近似信噪比：41.42 dB
- 近似 THD：1.41%
- 判定：良好

## 4 kHz

- 录音总时长：14.96 s
- 检出的稳定音段：13.397 s
- 估计频率：4000.013587 Hz
- 频率偏差：+0.013587 Hz
- 中位幅度：−54.72 dBFS
- 幅度标准差：1.53 dB
- 5%–95% 幅度范围：−57.46 至 −53.01 dBFS
- 相位残差标准差：23.57°
- 95% 相位残差绝对值：55.24°
- 相邻窗口最大相位跳变：11.65°
- 相干性：0.9202
- 等效路径误差：5.61 mm RMS
- 近似信噪比：52.24 dB
- 近似 THD：6.25%
- 判定：可用于原型

## 解释

线性相位斜率已用于估计实际录得频率，因此报告中的相位残差不包含播放设备与录音设备之间的固定时钟频差。1 kHz 与 4 kHz 的频率估计都只偏离目标约 0.01 Hz，说明测试期间播放与录音时钟整体稳定。

4 kHz 的相位角抖动较大，但其波长更短；换算后的等效路径误差约 5.6 mm，仍适合做第一轮 20–30 cm 孔径扫描。4 kHz 的约 6.25% THD 是端到端测量值，可能同时包含播放扬声器、房间、手机麦克风与系统音频处理，不能单独归因于手机。

## 下一阶段约束

- 首次移动扫描继续使用 4 kHz 稳定正弦。
- 扫描距离约 20–30 cm，时长约 10 s，手机朝向尽量固定。
- 扬声器与手机起始位置相距约 1 m。
- 同时保存音频硬件时间戳和 ARCore 位姿的单调时钟时间。
- 波束形成前先估计每次录音的实际载波频率，不能硬编码为恰好 4000 Hz。
- 相位质量低于当前 4 kHz 基线时，应拒绝生成可信声源热图。
