# 027 M4 测试几何定义纠正

日期：2026-09-26  
版本：0.10.3  
状态：测试方法已纠正，等待固定位置偏航实验

## 问题

此前的左右角度实验由用户手持手机并目测角度完成，而且没有明确区分平移、公转和手机绕自身中心偏航。结果可以证明双麦输出会随相对位置变化，但不能作为绝对角度误差或有效基线的标定数据。

## 几何定义

- **固定手机朝向、横向平移**：会改变声源在手机坐标中的入射角，方法有效，但需要量取前向与横向距离。手持目测只适合定性验证左右。
- **手机位置固定、绕自身中心偏航**：会改变声源在手机坐标中的入射角，且声源距离不变，是下一轮推荐方法。
- **手机绕声源公转并始终让背板正对声源**：声源在手机坐标中始终接近 0°，两条短边到声源近似等距，不能验证 ±30° 的声学角度映射。

## 实现修改

- 录制开始时把 IMU 相对航向归零。
- 实时界面新增“相对转角”，显示手机相对录制起点绕自身中心偏航的角度。
- 测试指南增加三种运动方式的明确区分，以及固定位置 `0° → +30° → 0° → −30° → 0°` 的推荐流程。
- 生成 `AcousticLens-v0.10.3-relative-yaw-test.apk`。

## 下一实验判据

手机和扬声器位置固定，只旋转三脚架云台。若手机相对起点转过角度 `Δψ`，声源在手机坐标中的声学角应近似反向变化 `−Δψ`。通过时间戳对齐 IMU 与声学特征后，评估符号、斜率、零点、滞后和稳定性。
