# 019 M3 三脚架结果与单频质量防护

- 测试条件：手机使用三脚架固定，播放五频 FFT-bin 对齐测试音。
- 应用版本：0.7.0。

## 实验结果

三脚架有效消除了手持姿态误差，但没有解决 550.8 Hz 的声学不稳定：

- 扫描范围 79.85°，满足至少 60° 的要求。
- 俯仰变化约 0.83°、侧倾变化约 0.60°，线性加速度均值约 0.029，说明旋转轨迹已经足够稳定。
- 550.78125 Hz：拟合分数 0.706、残差 48.88°、有效间距触及 20 cm 搜索上限，未通过。
- 703.125 Hz：拟合分数 0.982、残差 10.82°，略高于残差门槛。
- 855.46875 Hz 与 1148.4375 Hz 在本次会话内达到单次质量门槛，但不能代替主频 550.8 Hz 的认证。
- 550.8 Hz 的两个录音通道目标频率能量明显失衡；与此前成功会话相比，直达声占比下降，房间反射、桌面反射、扬声器方向性或麦克风遮挡成为更可能的原因。

结论：本次失败不是三脚架或旋转稳定性导致。当前算法拒绝该结果是正确行为，不能通过放宽分数、残差或有效间距门槛把它强行判为成功。

## 0.8.0 修改

1. 新增旋转平面锁定：以开始采集时的俯仰和侧倾为参考，任一方向偏差超过 3° 时暂停引导计时，并在界面显示当前偏差。
2. 每个频点新增左右通道能量平衡度 `balance_*`；主频平衡度低于 0.30 时标记为 `CHANNEL_IMBALANCE`。
3. 初始化结果增加 `primary_quality_status`，界面提示可区分通道失衡、相位不稳定、残差过大、有效间距异常和旋转范围不足。
4. 生成 550.78125 Hz、40 秒、−12 dBFS 的 FFT-bin 对齐单频测试音。单频文件把播放能量集中到主频，用于提高直达声相对反射和背景噪声的比例。
5. 应用版本升级为 0.8.0（versionCode 10）。
