# 开发进程报告 008：引导式设备初始化与手机端参数持久化

日期：2026-09-19  
版本：AcousticLens v0.5.0  
状态：实现完成，等待真机实验并冻结

## 本阶段问题

此前设备标定要求测试者自行保持参考声源居中并完成左右扫描，缺少角度、稳定时间和自动停止引导。该方式容易造成扫描覆盖不一致，也容易被误解为普通定位时必须预先知道声源位置。

## 已完成实现

1. 新增七阶段初始化状态机：中央稳定、转至左侧、左侧稳定、转至右侧、右侧稳定、返回中央、中央稳定完成。
2. 目标角为 −40°、+40°和 0°；角度来源为旋转矢量推导的镜头水平朝向，不依赖 ARCore。
3. 使用陀螺仪角速度判断是否真正静止。离开目标容差或运动过快时，稳定计时自动清零。
4. 相机画面新增角度轨道、当前角度点、目标角度圈、步骤编号、文字提示和稳定进度条。
5. 完成第七步后自动结束录音并进入设备参数计算。
6. `orientation.csv` 新增 `relative_heading_deg`；导出 ZIP 新增 `calibration_result.json`。
7. 新增手机端低频循环相位拟合器，计算相机—麦克风轴偏差、有效基线、相位残差和参与频段。
8. 可靠结果保存为 `PASS`；方向可辨识但基线偏弱的结果保存为 `PROVISIONAL`；不满足条件时为 `NOT_READY`。
9. `PASS` 或 `PROVISIONAL` 设备档案持久化到 App 私有目录，供后续普通未知声源定位模块读取。

## 产品边界

已知参考声源只用于首次设备初始化。普通定位模式不能要求用户预先知道声源位置，也不能要求未知声源始终位于镜头中央。当前版本实现的是初始化基础设施，尚未宣称完成普通未知声源热力图。
