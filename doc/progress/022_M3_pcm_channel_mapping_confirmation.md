# 022 M3 PCM 声道与物理麦克风映射确认

日期：2026-09-26

## 隐私边界

本轮经用户许可播放电脑测试音并使用手机麦克风。诊断结果明确记录 `raw_audio_saved: false`，只在 AcousticLens 私有目录保存汇总指标，没有保存、拉取或导出原始录音，也没有访问任何其他手机文件或应用。

## 测试条件

- 手机充电口所在短边正对电脑扬声器。
- 声源距离约 20 cm，手机保持静止。
- 播放 `test_noise_500Hz-8kHz_30s_-12dBFS.wav`。
- AcousticLens 0.9.0 使用 `CAMCORDER` 源采集 8.021 秒、48 kHz 双通道数据。
- Android 同时报告 `bottom` 与 `back` 两颗物理麦克风为活动状态。

## 本次结果

- 左声道 RMS：0.02794
- 右声道 RMS：0.02075
- 左/右 RMS 比：约 1.35
- 左声道峰值：0.4757
- 右声道峰值：0.2917
- 双声道相关系数：−0.260
- GCC-PHAT 中位时延：−21.64 samples
- GCC 峰值比：1.544
- 有效分析窗口：94

## 与背部朝向测试对照

上一轮背部朝向扬声器时，右声道 RMS 为 0.00953，左声道 RMS 为 0.00716，右声道约强 1.33 倍。本轮充电口短边朝向扬声器时，左声道约强 1.35 倍。

两组方向对照支持以下 PCM 映射：

- 左声道：`bottom` 物理麦克风
- 右声道：`back` 物理麦克风

系统报告两麦距离为 14.2567 cm；该基线在 48 kHz、声速 343 m/s 条件下对应约 19.95 个采样的最大远场时差。本次测得绝对时延 21.64 samples，与物理基线量级一致，少量超出可由近场摆位、扬声器尺寸、房间反射及厂商音频处理解释。

## 结论

本机已经确认存在可用的真实双物理麦克风采集路径。此前失败的主要系统性原因不是手机缺少麦克风，而是旧版 `VOICE_RECOGNITION` 仅启用一颗物理麦克风后生成处理双声道。0.9.0 改用 `CAMCORDER` 后，宽带 TDOA 定位具备真实硬件基础。

下一步应以系统麦克风坐标提供的 14.2567 cm 为固定基线，使用宽带 GCC-PHAT、频段响度差和 IMU 转动轨迹建立方向概率图，不再依赖 550.8 Hz 单频拟合基线。
