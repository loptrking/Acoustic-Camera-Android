# 开发进程报告 005：首次宽带旋转扫描实验结果

日期：2026-09-19  
输入会话：`result/AcousticLens_IMU_2026-09-19_145933_692.zip`  
状态：已完成并冻结

## 实验目的

使用 500 Hz–8 kHz 带限宽带噪声，验证 GCC-PHAT 时延和多频段双通道相位是否能够随手机方位角形成稳定、可重复的变化，为纯手机声源方向显示建立数据依据。

## 数据质量

- 录音时长：25.48 s。
- 格式：48 kHz、16-bit、2 channels。
- 姿态行数：1274。
- 姿态采样率中位数：49.865 Hz。
- 方位覆盖：92.694°。
- 起始方位：−90.698°。
- 结束方位：−97.808°。
- 前 2 秒方位中位数：−90.925°。
- 音频时钟拟合采样率：48,000.068 Hz。
- 音频时钟残差 p95：0.613 ms。
- 两声道不是复制信号，归一化差异中位数为 1.212。

采集长度、姿态覆盖、回到起始方向和音频时间戳均满足本轮分析需要。

## GCC-PHAT 结果

- GCC-PHAT 峰值比中位数：1.249，达到初步门槛 1.2。
- 时延范围：−24.0 至 +23.45 samples，部分窗口触及搜索边界。
- 时延—姿态模型 R²：0.307，低于目标 0.5。
- 模型残差 RMS：8.170 samples，高于目标 2 samples。
- 往返角度分箱：14 个。
- 同角度往返时延中位差：3.549 samples，高于目标 2 samples。
- 直接拟合有效基线：11.821 cm，但模型质量不足，不能作为标定值。

结论：宽带信号显著改善了 GCC 峰值明确程度，但单一 GCC 峰仍受多径、频率相关通道处理和异常窗口影响，尚不适合直接生成方向热点。

## 多频段相位结果

主能量附近约 542.9 Hz 的相位—姿态循环模型：

- 一致性：0.986。
- 相位残差 RMS：9.564°。
- 有效基线：4.022 cm。
- 拟合方向参数：−148°。

996.1 Hz 独立频段：

- 一致性：0.980。
- 相位残差 RMS：11.702°。
- 有效基线：5.5 cm。
- 拟合方向参数：−147°。

两个相互独立的低频频段给出几乎相同的方向参数，且有效基线均处于手机内部麦克风可能具有的水平投影范围。这排除了单一频率偶然拟合的主要疑虑，证明双声道中存在可随旋转重复的空间相位信息。

600 Hz 附近虽达到最低一致性门槛，但方向和基线与上述频段不一致；1.25 kHz 以上多数频段残差显著增大，可能受到房间多径、机身遮挡、波长缩短和厂商音频处理影响。第一版方向算法应选择经过质量筛选的低频频段，而不能无差别融合全部频率。

## 当前不能直接显示热点的原因

拟合得到的 −147° 是“声源方向与设备麦克风基线方向组合后的参数”，不是已经标定的摄像头画面方位。麦克风对的真实位置和轴向未知；同时，当前通过 `SensorManager.getOrientation` 得到的 Euler yaw 在手机竖直握持时不等价于摄像头光轴在水平面的前向角。

在没有完成“摄像头前向—麦克风基线”外参标定前，直接把 −147° 投影到画面会产生看似合理但没有物理依据的热点。

## 阶段决策

纯手机旋转扫描路线继续。算法主线从“单一 GCC-PHAT 峰”调整为：

1. 使用四元数计算摄像头前向矢量及水平投影角；
2. 在约 500 Hz–1.2 kHz 范围提取多个窄带互谱相位；
3. 按循环一致性和残差自动选择可靠频段；
4. 增加一次已知正前方声源的设备标定，求麦克风有效基线和轴向偏置；
5. 用正前、左 30°、右 30°三组已知方向实验验证角度误差；
6. 验证通过后再进入实时方向热点叠加。
