# 024 M4 宽带实时方向估计实现

日期：2026-09-26

## 输入依据

- Android API 确认 `CAMCORDER` 同时启用 `bottom` 与 `back` 两颗物理麦克风。
- 系统坐标给出两麦基线 14.2567 cm。
- 三方向实验确认：充电口侧为负 GCC 时延、屏幕左侧为正 GCC 时延、镜头正前方接近零时延。

## 实现内容

1. 新增 `BroadbandDirectionTracker`，以 48 kHz、14.2567 cm 基线和 343 m/s 声速计算最大物理时延。
2. 使用 `azimuth = asin(-lag / maxLag)` 将宽带 GCC 时延换算为前方半平面水平角度，正角度指向画面右侧。
3. 增加弱信号、相关峰不足、双声道差异不足、物理越界和时间不稳定等拒绝状态。
4. 使用最近九个合格窗口的时延中位数抑制离群值，并根据相关峰、时间稳定性和信号强度计算置信度。
5. `acoustic_features.csv` 新增实时宽带角度、置信度、质量状态和最大物理时延字段。
6. `metadata.json` 记录固定物理基线、方向模型、符号约定和活动物理麦克风。
7. 普通开始按钮改为持续宽带定位，不再启动 550.8 Hz 引导认证；会话由用户手动停止。
8. 相机界面新增半透明方向带、方向标线、角度、置信度和质量提示；方向越不确定，方向带越宽。
9. PRD 升级至 v0.5，正式主线从单频认证调整为真双麦宽带定位。
