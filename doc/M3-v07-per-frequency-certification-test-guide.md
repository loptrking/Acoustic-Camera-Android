# M3 v0.7 按频率双次认证测试指南

适用版本：AcousticLens v0.7.0

测试音频：`doc/test_multitone_fft_bins_550-1148Hz_40s_-12dBFS.wav`

## 版本变化

新版不再要求不同频率共享一组麦克风参数。550.78125 Hz作为首个正式支持频率独立认证；703、855、996和1148 Hz的异常结果不会再拖累550 Hz。

旧版v0.6的跨频率候选档案不会迁移，因此安装v0.7后需要重新完成两次会话。

## 第一次会话

1. 覆盖安装 `release/AcousticLens-v0.7.0-frequency-profile.apk`。
2. 开启自动旋转，手机顶部朝左、充电口朝右。
3. 播放设备关闭空间音频、杜比和均衡器，播放音量沿用上一轮成功的设置。
4. 扬声器置于镜头正前方0.5–0.8 m，从多音文件开头播放。
5. 在5秒内开始初始化，按七阶段引导完成扫描。
6. 若550 Hz质量合格，最终应显示“550.8 Hz候选已保存”。
7. 导出ZIP到`result`。

## 第二次会话

1. 将手机—扬声器整套布置换到另一个实际方向，距离、高度、音量不变。
2. 保持充电口朝右，从多音文件开头重新播放。
3. 完成第二次七阶段初始化并导出ZIP。
4. 若轴偏差差值不超过10°、有效基线相对差不超过30%，最终应显示“550.8 Hz双次认证通过”。

## 反馈内容

- 两次最终提示；
- 两个ZIP；
- 第二次是否显示正式通过；
- 横屏界面是否正常。

即使第二次没有通过，也不要继续重复测试；先导出数据以检查它是单次质量失败还是跨会话参数不一致。
