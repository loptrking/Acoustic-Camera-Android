# M3 引导式设备初始化测试指南

适用版本：AcousticLens v0.5.0

## 测试目的

确认 App 能依靠手机姿态传感器完成一套无需人工计时的初始化引导，并在会话结束后计算、保存和导出该手机的方向参数。

这不是日常寻找未知声源的使用流程。参考声源只在首次初始化时放在已知位置；后续普通定位模块会读取保存的设备档案。

## 准备

1. 安装 `release/AcousticLens-v0.5.0-guided-initialization.apk`。
2. 将另一部手机或扬声器放在测试手机正前方约 0.8–1.2 m，播放 `doc/test_noise_500Hz-8kHz_30s_-12dBFS.wav`，循环播放。
3. 测试手机竖直手持，位置尽量不平移；起始时只需让准星对准参考扬声器。
4. 环境尽量安静，避免手指遮挡手机麦克风孔。

## 操作流程

1. 打开 App，点击“开始引导初始化”。
2. 第 1 步保持手机不动。进度条走满后，App 自动进入下一步。
3. 按屏幕提示缓慢向左旋转。青色实心点是当前角度，橙色圆圈是目标角度；到达约 −40°后保持。
4. 按提示缓慢向右旋转至约 +40°并保持。
5. 按提示返回 0°并保持。流程完成后 App 会自动停止，不需要点击停止按钮。
6. 等待计算完成，记录界面显示的是“已通过”“暂定参数”还是“尚未形成可靠参数”。
7. 点击“导出上一次会话 · ZIP”，将 ZIP 保存到项目 `result` 文件夹。

## 需要回传的信息

- 导出的最新 ZIP；
- App 最终提示文字；
- 流程是否能自动从 1/7 走到 7/7并自动停止；
- 是否出现角度方向相反、跳变、长时间无法进入下一步或明显卡顿。

## 判定

- `PASS`：至少两个低频相位频段形成同一方向簇，扫描覆盖不少于 60°，有效基线和残差达到可靠门槛；设备档案持久保存。
- `PROVISIONAL`：方向簇和残差可用，但有效基线偏弱；保存暂定档案，后续必须做多个已知方向的复核。
- `NOT_READY`：数据不能支持稳定设备参数；保留原始会话供离线诊断，不输出伪定位结果。

若测试中途必须退出，可点击“手动停止并保存”，但该会话通常不应作为正式初始化结果。
